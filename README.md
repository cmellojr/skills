# Agent Skills

Curated agent skills by Carlos Mello Jr, organized by domain.

## Installation

```bash
# Install a specific skill
npx skills add cmellojr/skills --skill gcp-free-tier -y

# Install all skills
npx skills add cmellojr/skills -y
```

## Skills

| Skill | Description |
|---|---|
| [`gcp-free-tier`](gcp-free-tier/SKILL.md) | Keep a Google Cloud project strictly within the Free Tier: live resource audits, pre-deploy vetting, and billing budget guardrails. |
